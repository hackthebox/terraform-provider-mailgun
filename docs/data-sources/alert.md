# mailgun_alert (Data Source)

Use this data source to look up an existing Mailgun alert by ID. Alerts notify you when specific events occur in your Mailgun account.

## Example Usage

```terraform
# Look up an existing alert by ID
data "mailgun_alert" "example" {
  id = "12345678-1234-5678-1234-123456789abc"
}

# Use the alert information
output "alert_channel" {
  value = data.mailgun_alert.example.channel
}

output "alert_event_type" {
  value = data.mailgun_alert.example.event_type
}
```

## Schema

### Required

- `id` (String) The unique identifier of the alert (UUID format).

### Read-Only

- `channel` (String) The delivery channel for the alert: 'email', 'webhook', or 'slack'.
- `emails` (List of String) List of email addresses receiving alert notifications (when channel is 'email').
- `event_type` (String) The type of event that triggers the alert.
- `slack_ids` (List of String) List of Slack channel IDs receiving alert notifications (when channel is 'slack').
- `webhook_url` (String) The URL receiving webhook notifications (when channel is 'webhook').
