# mailgun_alert (Resource)

Manages a Mailgun alert. Alerts notify you when specific events occur in your Mailgun account.

**⚠️ Important**: Alerts are immutable. Any changes to an alert's configuration will require destroying and recreating the resource. This is a limitation of the Mailgun API which does not support updating alerts.

## Channel Configuration

Each alert must specify exactly one channel type with its corresponding settings:

- **Email Channel**: Requires `emails` - a list of email addresses to receive notifications
- **Webhook Channel**: Requires `webhook_url` - the URL to receive webhook notifications
- **Slack Channel**: Requires `slack_ids` - a list of Slack channel IDs (requires Slack integration)

## Example Usage

```terraform
# Alert with email notifications
resource "mailgun_alert" "email_alert" {
  event_type = "hard_bounces"
  channel    = "email"
  emails     = ["alerts@example.com", "ops@example.com"]
}

# Alert with webhook notifications
resource "mailgun_alert" "webhook_alert" {
  event_type  = "complaints"
  channel     = "webhook"
  webhook_url = "https://example.com/mailgun-alerts"
}

# Alert with Slack notifications (requires Slack integration)
resource "mailgun_alert" "slack_alert" {
  event_type = "unsubscribes"
  channel    = "slack"
  slack_ids  = ["C01234ABCDE", "C56789FGHIJ"]
}

# Using available event types from data source
data "mailgun_alert_events" "available" {}

resource "mailgun_alert" "dynamic_alert" {
  # Use the first available event type
  event_type = data.mailgun_alert_events.available.events[0]
  channel    = "email"
  emails     = ["alerts@example.com"]
}
```

## Schema

### Required

- `channel` (String) The delivery channel for the alert. Valid values: 'email', 'webhook', 'slack'.
- `event_type` (String) The type of event that triggers the alert. Use the mailgun_alert_events data source to get a list of valid event types. Examples: 'hard_bounces', 'complaints', 'unsubscribes'.

### Optional

- `emails` (List of String) List of email addresses to receive alert notifications. Required when channel is 'email'.
- `slack_ids` (List of String) List of Slack channel IDs to receive alert notifications. Required when channel is 'slack'. Requires Slack integration to be configured in your Mailgun account.
- `webhook_url` (String) The URL to receive webhook notifications. Required when channel is 'webhook'.

### Read-Only

- `id` (String) The unique identifier of the alert (UUID format).
